## Not used as features

| Column | Why |
|---|---|
| `case_id` | Join key only |
| `date_decision`, `MONTH`, `WEEK_NUM` | Time of application: used to split the data and for the drift correction, not as model inputs (a model cannot extrapolate time to future weeks) |
| `target` | The label: 1 = defaulted, 0 = repaid |
| `birth_259D` | Replaced by `age_years` |
| `num_group1`, `num_group2` | Row indexes inside depth-1/2 tables |
